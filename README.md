# Japheth Ralph Nyadwera Portfolio

A responsive, multi-page portfolio website and progressive web app (PWA).

## Features

- Separate home, about, portfolio, services, and contact pages
- Project search and category filters
- Persistent light and dark themes
- Installable app experience on supported browsers
- Offline access to the site pages and local assets after the first visit

## Hosting

The site is published with GitHub Pages:

https://38780431.github.io/japheth-ralph-portfolio-website/

Service workers require HTTPS or localhost. Open the hosted site once while online to install the service worker and cache the pages for offline use.
